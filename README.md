## Abstract

Healthcare organizations collect a large amount of data about patients, diseases, lifestyle, treatment, and hospital services. It is difficult to understand useful information from this data by looking at the records manually. This project aims to develop a Business Intelligence Dashboard for Healthcare Analytics to analyze healthcare data and present useful information in a simple way.

The project uses benchmark healthcare datasets containing patient, demographic, lifestyle, and medical information. The data will first be cleaned and analyzed using Exploratory Data Analysis (EDA) to find important patterns and relationships. Machine learning models such as Logistic Regression, Decision Tree, Random Forest, XGBoost, and CatBoost will be used to predict disease risk and compare their performance. SHAP and LIME will be used to understand which factors are important for the predictions. The results will then be presented using charts, graphs, heatmaps, feature importance plots, and an interactive dashboard.

The main goal of this project is to make healthcare data easier to understand and provide useful insights for data-driven healthcare decision-making.

## Objectives

1. To develop machine learning models for analyzing and predicting disease risk from benchmark healthcare datasets.
2. To integrate SHAP and LIME to provide clear and meaningful explanations of healthcare predictions.
3. To identify important lifestyle, demographic, and medical factors related to disease risk.
4. To evaluate and compare model performance and explainability, and develop an interactive healthcare dashboard.
